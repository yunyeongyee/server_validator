# 목업 화면

버튼별 동작은 [사용자 흐름 정의](../user-flow.md)에 있습니다. 아래 이미지는 실제 브라우저 실행을 캡처한 것으로, 클릭 가능한 도구는 저장소 루트에서 `run.bat 또는 python launcher.py`으로 실행합니다.

1. [문서 입력](01-input.png)
2. [공통 사양·추출값 검토](02-review.png)
3. [요구사항 예비 판정](03-results.png)
4. [실제 XR 이미지에서 편집 흐름 연습](04-composition.png)
5. [모바일 입력 화면](05-mobile.png)

4번 화면은 사용자가 제공한 XR 스텐실의 실제 이미지입니다. R760/R660 견적의 서버 이미지가 아니며, 화면에도 ‘XR 편집 연습’으로 구분합니다. R760/R660은 RackServers 원본을 도구의 ‘스텐실 가져오기’로 가져온 후 선택합니다.

# Windows에서 실행하고 큰 스텐실 가져오기

## 실행

1. GitHub main의 **Code → Download ZIP** 또는 `dist/ServerValidator-Mockup.zip`을 다운로드하고 폴더에 압축 해제합니다. 두 방식 모두 `web/` 화면이 포함됩니다.
2. 공식 Python 3.10 이상을 설치합니다.
3. **run.bat를 더블클릭**합니다. 처음 실행 시 가상환경과 FastAPI/Pillow 의존성을 설치합니다.
4. 브라우저가 자동으로 열립니다. 실행 창은 유지합니다.
5. **예제 불러오기 → 두 문서 예비 분석**으로 목업을 확인합니다.
6. 종료는 실행 창에서 Ctrl+C입니다.

화면은 브라우저지만 서버는 내 PC에서만 실행합니다. **도메인·호스팅·Node.js는 필요 없습니다.** ZIP에 React 빌드 결과가 포함됩니다. 첫 Python 패키지 설치에는 인터넷이 필요합니다. 기본 포트 8000을 유지해야 브라우저의 임시 저장도 같은 위치에서 복원됩니다. 실행 중이면 기존 인스턴스를 엽니다. `start.cmd`로 실행해도 run.bat로 연결됩니다.

## RackServers 원본 가져오기

1. 왼쪽 **이미지 보관함**을 누릅니다.
2. **스텐실 가져오기**를 누릅니다.
3. PC의 **Dell-PowerEdge-RackServers.vssx 원본**을 선택합니다.
4. 실제 내장 이미지 추출을 기다립니다.
5. R760/R660을 검색해 모델·방향·섀시 옵션을 확인합니다.
6. **서버 이미지 구성 → 서버 이미지 선택**에서 실제 모델과 방향이 같은 이미지를 연결합니다.

도구의 한도는 **128MB**입니다. 채팅 첨부의 32MB 한도와 별개입니다. 추가 이미지는 `%LOCALAPPDATA%\ServerValidator\assets`에 저장합니다. EMF/WMF 변환은 Windows Inkscape의 `inkscape.exe`가 PATH에 있어야 합니다. 변환 실패 시 Visio에서 해당 실제 원본을 PNG로 내보내 **이미지 추가**로 넣습니다(장당 20MB 이하). 128MB보다 큰 파일은 필요한 모델만 별도 스텐실이나 PNG로 저장합니다. XML 도형을 임의로 재생성하지 않습니다.

## 선택적 OpenAI

OpenAI 없이도 예비 추출과 화면 검토가 됩니다. 연결하려면 `run.bat --ai`로 SDK를 설치하고 환경 변수에 키를 설정합니다. `SV_OPENAI_API_KEY` 또는 `OPENAI_API_KEY`, 선택적으로 `OPENAI_MODEL`을 사용합니다. 키는 채팅이나 소스·보정 파일에 넣지 않습니다. 분석 실패 시 예비 추출로 전환한 사실을 표시합니다. 실제 키로 하는 OpenAI 호출은 현재 미검증입니다.

## exe 포장

`scripts\build_windows.cmd`를 **Windows에서** 실행하면 PyInstaller로 `dist\ServerValidator.exe`를 만들도록 구성했습니다. 미리 빌드된 `web/` 화면이 필요합니다. exe에는 FastAPI/Pillow·React 화면·실제 XR 이미지가 포함되고, Inkscape는 별도 설치입니다.

현재 작업 환경은 Linux여서 **Windows 배치 파일·exe의 실제 실행을 검증하지 않았습니다.** 전달하는 ZIP은 Python 실행 버전이며 exe가 포함된 버전이 아닙니다.

## 어떤 배포가 적절한가

| 방식 | 사용 상황 | 도메인 |
|---|---|---|
| 로컬 웹 + run.bat | 현재 목업 검토·PC에서 문서 작업 | 필요 없음 |
| 로컬 exe | Python 설치 없이 더블클릭 실행 | 필요 없음. Windows 빌드·검증 필요 |
| 공유 웹 | 팀 공동 작업·권한·공유 저장 | 자체 도메인은 선택. 호스팅 제공 주소로 시작 가능 |

현재는 로컬 웹으로 흐름을 확정하고 이후 exe나 공유 웹으로 확장합니다. 보정 파일을 다른 견적에 가져오면 이전 부품 배정을 해제하며, 좌표와 이미지 연결은 사용자 PC에서 관리하고 커밋하지 않습니다.

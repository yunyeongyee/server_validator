# 내 PC에서 실행하고 스텐실 넣기

## 가장 간단한 방법: 로컬 웹 목업

도메인과 호스팅을 구매할 필요가 없습니다. 화면은 브라우저에서 열리지만 서버는 내 PC에서만 실행합니다.

1. 제공한 ZIP을 **폴더에 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
2. Windows에 Python 3.10 이상을 설치합니다. 공식 Python 설치 프로그램을 사용합니다.
3. 폴더의 **start.cmd를 더블클릭**합니다.
4. 브라우저가 자동으로 열립니다. 열린 검은 실행 창은 유지합니다.
5. **예제 불러오기 → 두 문서 예비 분석**을 눌러 목업을 살펴봅니다.
6. 종료할 때 실행 창에서 Ctrl+C를 누릅니다.

이미 실행 중이면 기존 인스턴스의 화면을 다시 엽니다. 기본 포트는 8000이며 같은 포트를 사용해야 브라우저의 임시 저장도 같은 위치에서 복원됩니다.

명령으로 실행하려면 저장소 폴더에서 `py -3 launcher.py`를 실행합니다. Python을 설치하지 않고 쓸 단일 exe는 아래 Windows 빌드가 필요합니다.

## 큰 RackServers 스텐실 가져오기

1. 목업 왼쪽 **이미지 보관함**을 누릅니다.
2. 오른쪽 위 **스텐실 가져오기**를 누릅니다.
3. PC에 있는 **Dell-PowerEdge-RackServers.vssx 원본**을 선택합니다.
4. 내장 이미지가 추출될 때까지 기다립니다.
5. 검색칸에 **R760** 또는 **R660**을 넣어 실제 모델·전면·후면 이미지를 확인합니다.
6. 4단계 **서버 이미지 구성**에서 **서버 이미지 선택**을 눌러 모델과 방향이 같은 이미지를 연결합니다.

채팅 첨부 전송의 **32MB 제한**과 이 도구의 가져오기 제한은 다릅니다. 로컬 도구는 **128MB 이하** 스텐실을 처리합니다. 변환된 이미지는 Windows의 `%LOCALAPPDATA%\ServerValidator\assets`에 저장합니다. 화면에서 실제 이미지의 원본 이름과 출처를 확인합니다.

원본이 EMF/WMF를 포함한다면 **Inkscape가 필요**합니다. Windows Inkscape를 설치하고 `inkscape.exe`가 PATH에 있어야 합니다. 또는 Visio에서 필요한 R760/R660 전면·후면을 **실제 원본 PNG로 내보내고**, 보관함의 **이미지 추가**로 넣을 수 있습니다. 이미지 추가는 장당 20MB 이하입니다.

128MB보다 크거나 지원 내장 이미지가 없다면 필요한 모델만 별도 스텐실로 저장하거나 PNG로 내보내세요. XML 도형을 임의로 다시 그려 대체하지 않습니다. 내장 이미지 추출은 전체 Visio 마스터의 레이어·텍스트·회전을 완전히 재현한 결과와 다를 수 있습니다.

## exe로 만드는 방법

`scripts\build_windows.cmd`는 **Windows에서** PyInstaller로 `dist\ServerValidator.exe`를 만들도록 준비한 빌드 스크립트입니다. exe를 더블클릭하면 로컬 서버와 브라우저 화면이 열립니다. 실행 창을 닫으면 서버도 종료됩니다. exe 안에 웹 화면과 제공된 실제 XR 이미지가 포함됩니다.

현재 작업 환경은 Linux여서 **Windows exe를 빌드·실행 검증하지 않았습니다**. ZIP은 Python 소스 실행용이며 exe가 들어 있다고 주장하지 않습니다. Windows에서 빌드한 뒤 실제 실행·파일 업로드·PNG 저장을 확인해야 배포할 수 있습니다. Inkscape는 exe에 포함하지 않습니다.

## 로컬 프로그램과 공개 웹 비교

| 방식 | 적합한 상황 | 도메인 | 비용/조건 |
|---|---|---|---|
| 로컬 웹 도구 | 지금 목업 검토, 문서·좌표를 내 PC에서 작업 | 필요 없음 | Python 또는 Windows exe. OpenAI를 연결하면 별도 API 비용 |
| 로컬 exe 포장 | 사용자가 Python 없이 더블클릭 실행 | 필요 없음 | Windows 빌드·실행 검증과 업데이트 배포 필요 |
| 공유 웹 서비스 | 여러 영업·기술 담당자의 팀 작업 | 자체 도메인은 선택 | 호스팅 제공 주소로 시작 가능. 인증·권한·공유 저장·운영 비용 필요 |

현재 추천은 **로컬 웹으로 사용자 흐름 확정 → 필요하면 exe 포장 → 팀 공유가 필요하면 웹 배포**입니다. 웹 화면 코드를 유지할 수 있어 UI를 다시 만들 필요가 없습니다.

보정 좌표·이미지 매핑은 브라우저에 저장합니다. 필요하면 **보정 파일 내보내기**로 사용자 PC에 JSON을 저장하세요. 다른 견적에 같은 보정 파일을 가져오면 부품 배정을 해제해 잘못된 구성을 재사용하지 않습니다. 이 파일은 저장소에 커밋하지 않습니다.
